# 法律文库系统优化方案

## 1. 服务器启动配置优化

### 问题分析
- 当前法律文库模块在模块导入时初始化，可能导致服务器启动时未完全就绪
- 异步初始化过程可能影响智能助手实时访问法律文库资源
- 缺少统一的初始化机制确保服务器启动后法律文库完全可用

### 解决方案

#### 1.1 创建服务器启动初始化文件
- 创建 `lib/server-init.ts` 文件，实现法律文库的同步初始化
- 使用 Next.js 的 Server Components 机制确保在服务器启动时执行初始化

#### 1.2 优化 LocalLegalLibrary 初始化逻辑
- 修改 `lib/local-legal-library.ts` 中的初始化方法
- 实现同步初始化选项，确保在服务器启动时完成所有加载操作
- 添加初始化状态检查和超时处理

#### 1.3 集成到 Next.js 应用启动流程
- 在 `app/layout.tsx` 中添加服务器端初始化代码
- 使用 React Server Components 确保初始化在服务器端执行
- 实现初始化状态传递，确保客户端了解法律文库状态

## 2. 法律文本显示功能改进

### 问题分析
- 当前法律文本直接完整显示，对于长文本可能导致页面过长
- 缺少文本缩略显示功能，影响用户快速浏览
- 缺少展开/收起交互，用户体验不佳

### 解决方案

#### 2.1 创建可复用的文本展开/收起组件
- 创建 `components/TextExpandable.tsx` 组件
- 支持自定义缩略长度、展开/收起文本和过渡效果
- 实现平滑的高度和内容过渡动画

#### 2.2 优化法律文本显示
- 修改 `app/legal-library/page.tsx` 中的内容显示区域
- 使用新创建的 `TextExpandable` 组件包装法律文本
- 实现默认缩略显示，点击展开查看完整内容

#### 2.3 增强用户体验
- 添加展开/收起状态的平滑过渡效果
- 实现响应式设计，适配不同屏幕尺寸
- 添加展开/收起按钮的动画效果
- 确保文本内容完整加载和存储，不影响搜索和高亮功能
